What it does

Stay in flow.
Let the HUD watch.

It sits at the edge of your screen, out of the way, and speaks up only when a session needs you.

Permissions

Answer prompts from the HUD

Allow, Always or Deny and Claude carries on. Questions with options show up as buttons you can tick, with a typed answer when none fits.

Cost control

Catch runaway sessions

A session burning tokens fast gets flagged. Compact it, or start a fresh one in the same workspace with a handoff note built from the old transcript.

Limits

Rate limits, with a forecast

Reset countdowns, and whether your pace will last until the reset. Usage from other devices counts too.

Toasts

Reply right from the toast

When Claude finishes, a toast slides in. Type a reply and it lands in that session. Payment and access errors alert you too.

Every session at a glanceSorted by what needs you first and grouped by workspace, with live subagents.
Keyboard firstA global hotkey and full keyboard control, with search across sessions.
Private by designEverything stays on your machine. No account, no server, no telemetry.

Get it

Install in under a minute

Two platforms, one project. Both builds are published automatically from the repository on every release.

macOS

  1. Needs macOS 14 or newer.
  2. Run the Homebrew command, or download the zip and drag the app to Applications.
  3. Allow Accessibility access so the HUD can land in the right editor window.
brew install --cask louayzouaoui1/claude-hud/claude-hud Download for macOSUniversal · Apple silicon + Intel

Windows

  1. Runs on x64, ARM64 and x86. Nothing else to install.
  2. Download and unzip the archive.
  3. Double-click Install Claude HUD.cmd. The same step updates it later.
Windows may show a SmartScreen notice because the app is not code-signed yet. Choose “More info”, then “Run anyway”. Download for Windowsx64 · ARM64 · x86

Claude HUD works with Claude Code in Cursor, VS Code, and any terminal. It reads local session data through Claude Code's own hooks.
